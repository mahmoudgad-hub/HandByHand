# Default portraits

- child-girl.png and child-boy.png: user-supplied artwork.
- adult-woman.png and adult-man.png: generated with the built-in ImageGen tool, using the corresponding child artwork as a style reference.

Generation prompts: square head-and-shoulders avatar, friendly polished cartoon style matching the reference, clearly adult proportions around age 30, brown hair, warm smile, no text or watermark. Woman: shoulder-length hair without bow, modest pink blouse and pink circular backdrop. Man: short hair, neatly trimmed beard, blue collared shirt and blue circular backdrop. White outside the circle; face large and fully visible.

The portal prefers the authorized child-photo endpoint. Without an accessible photo, gender and birth date select the fallback (adult from the eighteenth birthday). Missing or invalid demographics remain neutral. Card accents follow gender, never list position.
