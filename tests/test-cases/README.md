# test-cases — حالات الاختبار المستقلّة

هذا المجلد **ليس** بديلًا عن `tests/db/pN_verify.sql` ولا عن `tests/api/a1_verify.sh`.
تلك مجموعات القبول التي يكتبها من بنى المرحلة، وهي التي تقرّر قبولها.
ما هنا **تشغيلة اختبار مستقلّة على ما خلص فعلًا**: قراءة الكود بعين من لم يكتبه،
وأسئلة لا تُطرح عادةً في المجموعة التي كتبها صاحب النقطة.

كل سيناريو هنا **مكتوب قبل تشغيله**، وله معرّف، ونتيجة مسجَّلة بتاريخها.

## التشغيل

المجموعتان X1 وX2 تبنيان تجهيزتهما وتهدمانها، وتطبعان حكمهما، وترجعان كود خروج
غير صفري عند أي فشل — نفس قواعد الخمسة في `tests/api/lib.sh`.

```bash
bash tests/test-cases/run/x1_run.sh
```

```bash
API_BASE=http://127.0.0.1:8090 bash tests/test-cases/run/x2_api_probe.sh
```

### ولا تُشغَّل على القاعدة المشتركة وأحد آخر يعمل عليها

كل مجموعة تبدأ بـ `DROP SCHEMA … CASCADE` وتبني صفوفها في قاعدة `hbh` نفسها،
وX1 تبني **مركزًا ثانيًا كاملًا**. تشغيلتان معًا تهدمان تجهيزة بعضهما في منتصف
الطريق. حصل فعلًا في أثناء كتابة هذا المجلد: تشغيلتي اصطدمت بـ `db.sh reset`
لزميل، فظهرت **خمس عشرة حالة فشل** ليست أخطاء على الإطلاق — وقراءتها الأولى كانت
«تسريبات». راجع **F-02** في [`04-findings.md`](04-findings.md).

فإن كان أحد يعمل، شغّل على نسخة خاصّة:

```bash
docker run -d --name hbh-db-x1 -e POSTGRES_DB=hbh -e POSTGRES_USER=hbh_owner -e POSTGRES_PASSWORD=hbh_dev_only_change_me -e "POSTGRES_INITDB_ARGS=--encoding=UTF8 --locale=C" -e TZ=UTC -e PGTZ=UTC -p 5445:5432 postgres:17-alpine postgres -c timezone=UTC -c log_timezone=UTC
```

ثم طبّق الهجرات والبذور عليها، وشغّل:

```bash
X1_CONTAINER=hbh-db-x1 bash tests/test-cases/run/x1_run.sh
```
