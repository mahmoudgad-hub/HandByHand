# UX Clarity Audit — هل يعرف كل شخص خطوته التالية؟

2026-09-14. التقييم heuristic من نصوص القوالب وشروط العرض والأفعال وعقود البيانات. لم يُجرَ اختبار خمس ثوانٍ مع مستخدمين أو قياس نقرات على نسخة حية. رموز الشاشات من [09](09-SCREEN-TO-SCREEN-MAP.md)، والدليل من [02](02-MASTER-JOURNEY-MAP.md). درجات الموبايل والأداء ذات ثقة أقل حتى المعاينة الفعلية.

## قاموس صياغات يفهمها ولي الأمر

| مفهوم داخلي | صياغة الواجهة المقترحة | الإجراء/الوعد الذي يجب ربطه |
|---|---|---|
| Treatment plan | برنامج جلسات طفلك | الخدمات والأهداف والتكرار ومن يتابع الطفل |
| Assessment result | ملخص التقييم والخطوة المقترحة | تقرير منشور وتاريخ واسم أخصائي |
| Receipt review pending | استلمنا إثبات الدفع ونراجعه الآن | متى نرد وماذا يحدث للموعد خلال الانتظار |
| ENROLLED | تم إنشاء ملف طفلك | لا «بدأ العلاج» قبل الخطة/الجدولة |
| CONFIRMED | موعد مؤكد يوم … | لا «دفعت» إذا لم يثبت التحصيل |
| CHECKED_IN | تم تسجيل حضور طفلك | ينتظر بدء الجلسة، لا «الجلسة جارية» |
| DRAFT report | الملخص قيد الإعداد | عند تأخره يظهر موعد التوقع، لا محتوى داخلي |
| Goal value | وصل إلى … من الهدف … | آخر قياس؛ لا تقدم إن لم توجد قياسات |
| EXHAUSTED | اكتملت الجلسات المتاحة في الباقة | ما التالي: مراجعة/تجديد وفق توصية |

النصوص العربية موجودة بالفعل في معظم الشاشات؛ المشكلة ليست استعمال كلمات إنجليزية في كل مكان. لا نسجل مصطلحًا داخليًا ظاهرًا دون دليل. مقترحات الجدول تضبط المعنى عندما تُوصل الأفعال الناقصة.

| apply layout | عمود واحد تحت 940/600؛ aside مخفي | فحص مصدر جيد؛ لا ادعاء pixel-perfect |
| parent data | cards/rows أكثر من جداول معقدة | حافظ على اسم الطفل في بطاقات مال الأسرة |
| slots | يتبع اختيار الخدمة والأخصائي والنمط | قائمة يومية مع وقت+مكان، لا شبكة أسبوع ضيقة |
| modals | dialog/HbhModal في ops وOTP overlay | تحقق focus trap وEscape والرجوع وعدم فقد المسودة |
| ops tables | guardians/matrix/ledgers واسعة | بطاقة اسم+حالة+فعل، والتفاصيل عند الفتح؛ مصفوفة الخدمات تصبح قائمة |
| reports/progress | نصوص وقيم وأعمدة chart | اختبر التفاف الأسماء والعربية/الأرقام؛ عرض تاريخ كامل بدل تكرار اسم شهر إن تعددت القياسات |

مصفوفة الاختبار الحي المطلوبة: 360×800 و390×844 و768×1024 و1440×900؛ portrait/landscape؛ لوحة مفاتيح مفتوحة؛ zoom 200%؛ نص عربي طويل؛ أسرة بطفلين؛ فشل شبكة. النجاح: لا overflow أفقي في parent task الأساسية، الاسم والـCTA واضحان، تركيز يعود لمصدر modal، لا تختفي الأخطاء خلف لوحة المفاتيح. **هذه معايير قبول لم تُنفذ في هذه المراجعة.**

## الشاشات التي تدمج والشاشات التي تبقى

إبقاء الدمج المنفذ reports/progress وmessages/requests وmy-day/appointments. اقتراح تقليل معاينة guardian الموازية للتفاصيل إلى quick view مختصر ثم صفحة واحدة للعمل. لا ندمج سجل الإشعارات مع المهام: الأول «ماذا حدث»، والثاني «ما الذي يلزمني». لا نضيف dashboards للأقسام الناقصة؛ نضيف عملًا داخل details/tasks/billing القائمة، كما يشرح [13](13-RECOMMENDED-TARGET-JOURNEY.md).
