## 1. ما هي البوابة

`web/portal` — تطبيق Angular 20، **يعمل على الهاتف أولًا**، بالعربية وباتجاه RTL،
لوليّ الأمر وحده. عمود بعرض 520px متوسّط، وهذا هو الشكل النهائي المقصود لا مرحلة
مؤقّتة نحو سطح المكتب.

`web/ops` — تطبيق المركز، بديل APP 115 في APEX. **تطبيق Angular ثانٍ قائم فعلًا** —
له قشرته وقائمته ومصادقته وشاشة دخول وشاشات موارد. دخل النطاق بقرار المالك D-26.

> `web/README.md` ما زال يقول إن `ops/` «خارج النطاق الآن — APEX 115 يقوم بعمله»،
> وده بيان بائت نقضه D-26 والكود نفسه. يحتاج تحديثًا.

ثلاث حقائق تشرح معظم قرارات الكود:

- **ولي أمر على هاتف، في غرفة انتظار، على شبكة متقطّعة.** ولذلك يوجد شريط «غير
  متصل»، وحالة خطأ فيها زرّ إعادة محاولة في كل شاشة، وجلسة في `sessionStorage`
  لا `localStorage` لأن الجهاز قد يكون مشتركًا في البيت.
- **الواجهة لا تقرّر شيئًا.** كل قاعدة عمل في PL/pgSQL، والـ API ينقل، والواجهة
  ترسم الإجابة. إخفاء زرّ ليس ضابطًا.
- **بثّ مباشر فقط، ولا تسجيل أبدًا.** ولذلك شاشة البثّ بلا شريط تقدّم وبلا تنزيل
  وبلا أرشيف — لا لأن الميزة مؤجّلة، بل لأنه لا يوجد شيء لتشير إليه.

## 2. التشغيل

```bash
npm --prefix web install
```

```bash
npm --prefix web start          # portal
npm --prefix web run start:ops  # ops
```

`web/` هو الـ workspace: مشروعان (`portal` و`ops`) وثالث للمشترك (`shared`)،
و`angular.json` واحد في `web/`. لا `package.json` داخل `portal/` أو `ops/`.

يعمل بالكامل **بلا قاعدة بيانات وبلا خدمة Go**، لأن `useFixtures: true` في
[`core/config/portal-config.ts`](../web/portal/src/app/core/config/portal-config.ts)
يبدّل كل نداء إلى `FixturePortalApi`. اقرأ [§10](#10-الفجوة-المفتوحة--عقد-الـ-api)
قبل أن تطفئ المفتاح.

```bash
npm --prefix web test
```

`.claude/launch.json` معدّ لتشغيل الخادم على المنفذ 4271.

## 3. الطبقات

```
web/
├─ angular.json        ← ثلاثة مشاريع: portal · ops · shared
├─ package.json        ← واحد للـ workspace كله
│
├─ shared/src/         ← ما يستعمله التطبيقان. يُستورَد بـ @hbh/shared/…
│   ├─ format/            UTC ← نصّ. المكان **الوحيد** لهذا التحويل
│   ├─ i18n/              الحزمة، والجمع، والمفتاح ← نصّ
│   ├─ config/            كل قرار محلّي كبارامتر — لا حرف واحد في مكوّن
│   ├─ icon/ · sprite/    أيقونة واحدة من مصدر واحد
│   ├─ toast/ · ui/       تأكيد، هيكل تحميل، حالة فراغ، ملاحظة خطأ
│   └─ a11y/              إعلان الشاشة للقارئ الصوتي، وانقطاع الشبكة
│
├─ portal/src/
│   ├─ styles/            hbh-shared · hbh-app · hbh-parent · portal.css
│   └─ app/
│       ├─ core/          api (PortalApi مجرّد + HTTP + fixtures) · auth ·
│       │                 models · alerts  ← لا يرسم شيئًا
│       ├─ layout/shell/  الترويسة وشريط التبويبات والحاوية
│       ├─ features/      شاشة لكل مجلد: .ts + .html (+ .css)
│       └─ shared/ui/     ما يخصّ البوابة وحدها: صفّ موعد، شارة حالة
│
└─ ops/src/               نفس الشكل: styles · core · layout · features
```

**قاعدة الاتجاه: `features` تعتمد على `core` و`@hbh/shared`. ولا شيء في `core`
يعرف شاشة، ولا شيء في `shared/` يعرف أيًّا من التطبيقين.** لو احتجت أن تستورد
شاشة داخل `core`، أو `PortalApi` داخل `shared/`، فالتصميم انقلب.

## 4. ثلاث عشرة قاعدة يمشي عليها التيم

كلها مطبَّقة في الكود القائم اليوم. الخروج عنها يحتاج سببًا مكتوبًا، لا صمتًا.

1. **مكوّنات standalone + `ChangeDetectionStrategy.OnPush` في كل مكوّن.** بلا استثناء
   حتى الآن. لا `NgModule` في المشروع.
2. **Signals للحالة، RxJS للنقل.** الحالة `signal()` و`computed()`؛ الـ HTTP يرجع
   `Observable` ويُغلق بـ `takeUntilDestroyed()`. لا اشتراك بلا إنهاء.
3. **`templateUrl` منفصل للشاشات، وقالب سطري للمكوّنات الصغيرة.** الحدّ العملي في
   الكود: أكثر من ~٢٥ سطر HTML ← ملف مستقلّ.
4. **لا نصّ عربي داخل قالب.** كل نصّ مفتاح في `ar.json` عبر `| t`. المفتاح المفقود
   يظهر على الشاشة كمفتاحه — عمدًا، لأن الفراغ لا تراه العين.
5. **لا `hex` في أي ملف CSS إلا `#fff` فوق تعبئة ملوّنة.** كل لون توكن في
   `hbh-shared.css`. ويحرسها `tests/web/w1_contrast_verify.sh`.
6. **`html/` هو مصدر نظام التصميم، و`web/*/src/styles/` نسخ مولَّدة.**
   `scripts/sync-design.sh` بينسخ `hbh-shared.css` و`hbh-parent.css`
   و`app/hbh-app.css` و`hbh-admin.css` و`hbh-screens.css` والشعار والـ sprite
   من `html/` إلى التطبيقين. **عدِّل `html/` ثم شغّل السكربت** — التعديل على نسخة
   يُمسح صامتًا عند أول مزامنة، وهو بالضبط الشكل الذي يصنع نسختين تتخالفان.
   الاستثناء الوحيد: `portal.css` و`ops.css` — كل منهما طبقة تطبيقه ولا تُزامَن.
7. **لا تنسيق تاريخ أو رقم خارج `FormatService`.** ولا `new Date().toLocaleString()`
   في أي مكان.
8. **لا بيانات شخصية في مسار ولا في معامل استعلام.** معرّف الطفل يسافر في المسار
   كمعرّف معتِم؛ الاسم والهاتف والكود لا يسافران أبدًا.
9. **معرّف الطفل ليس في الـ route.** يعيش في `ChildContextService`، لأن مسارًا فيه
   معرّف يوحي بأن تعديله يغيّر ما يُرى — والخادم هو من يقرّر.
10. **الخصائص المنطقية لا الاتجاهية.** `inset-inline-start` لا `left`،
   `margin-inline-start` لا `margin-right`. التطبيق RTL بالكامل.
11. **التعليقات إنجليزية، ونصوص الواجهة عربية.** ولا رمز تعبيري في كود يُشحن.
12. **اختبار الوحدة بجوار الكود (`*.spec.ts`)، واختبار القبول في `tests/`.**
    السبب في `README.md`: الـ builder يفرضه.
13. **`readonly` على كل حقل في نموذج.** النماذج في `portal.models.ts` كلها
    `readonly` — نماذج قراءة، لا كائنات تُعدَّل.

## 5. أنماط الشاشة

كل شاشة تتبع نفس الهيكل. انسخه، لا تخترع بديلًا:

```ts
export class Progress {
  private readonly api = inject(PortalApi);
  private readonly childContext = inject(ChildContextService);
  private readonly destroyRef = inject(DestroyRef);

  protected readonly data = signal<ProgressOverview | null>(null);
  protected readonly loading = signal(true);
  protected readonly failed = signal(false);

  constructor() { this.load(); }

  protected load(): void {
    this.loading.set(true);
    this.failed.set(false);
    this.api.progress(this.childContext.requireId())
      .pipe(takeUntilDestroyed(this.destroyRef))
      .subscribe({
        next: (v) => { this.data.set(v); this.loading.set(false); },
        error: () => { this.loading.set(false); this.failed.set(true); },
      });
  }
}
```

وفي القالب، **الحالات الأربع كلها إلزامية** — تحميل، فشل، فراغ، بيانات:

```html
@if (loading())      { <hbh-skeleton [count]="3" shape="row" /> }
@else if (failed())  { <hbh-error-note … (retry)="load()" /> }
@else if (empty())   { <hbh-empty-state … /> }
@else                { … }
```

شاشة بلا حالة فراغ تعني أن ولي أمر جديد بلا مواعيد يرى صفحة بيضاء ويظنّها عطلًا.

### القشرة تُخبَر عن نفسها من الـ route

`Shell` **لا يحمّل أي بيانات**، فعطبُ شاشة لا يأخذ التنقّل معه. العنوان وزرّ الرجوع
والتبويب النشط كلها في `data` في `app.routes.ts`:

```ts
data: { titleKey: 'nav.schedule', subtitle: 'child', tab: 'schedule' }
```

شاشة جديدة = مسار جديد + `data` + مكوّن. لا تلمس `shell.html`.

### شكلان من الشاشة

- **خارج القشرة** — `login`, `otp`, `welcome`: لكلٍّ طريق واحد للأمام وطريق واحد
  للخروج، فلا شريط تبويبات يعرض مخرجًا لا يؤدّي لشيء.
- **داخل القشرة** — الباقي كله.

## 6. العربية والأرقام والوقت — أكثر جزء يُخطئ فيه القادم الجديد

### الوقت

**كل لحظة تصل UTC وتُقارَن UTC.** `FormatService` هو المكان الوحيد الذي تصير فيه
اللحظة نصًّا، وهو **يسمّي المنطقة الزمنية صراحةً في كل مرة**. قراءة تاريخ بلا منطقة
هي بالضبط العيب الذي حرّك ساعات هذا المشروع ساعتين بصمت، وعطّل قفل الحساب، وأبطل كل
رمز تحقّق لحظة إصداره.

وأجزاء التاريخ تُقرأ من `formatToParts` لا بتقطيع نصّ منسّق: `ar-EG` تكتب التاريخ
`DD/MM/YYYY`، والتقطيع كان سيبدّل اليوم بالسنة ويجعل كل عمر خاطئًا بعقود.

### شكل الأرقام — قراران مختلفان، لا واحد

| الشكل | أين | الأنبوب |
|---|---|---|
| **عربية-هندية** ٦ | الأعمار والتواريخ والعدد داخل نثر عربي | `hbhCount`, `hbhDate` |
| **لاتينية** 6 | الساعة، المال، أرقام الفواتير، النِّسب، المعرّفات | `hbhNum`, `hbhTime`, `hbhMoney` |

وهذا ما تفعله المطبوعات الورقية للمركز نفسه. وكل عنصر يحمل رقمًا لاتينيًّا داخل
سياق RTL يحتاج `dir="ltr"` وإلا انقلب ترتيبه.

### الجمع — ستّ صيغ لا اثنتان

العربية لا تملك جمعًا واحدًا. مركز أطفال يصطدم بالحالات الصعبة كل يوم: طفل في
سنته الأولى، وطفل عمره سنتان، وثلاثة إلى عشرة، ثم أحد عشر فما فوق — لكلٍّ صيغة.
سلسلة واحدة `"{count} سنوات"` تطبع **«١ سنوات»**، وهذا خطأ مطبوع أمام أهل الطفل.

فالحزمة تحمل `child.age.one` و`.two` و`.few` و`.many` و`.other`،
و`Intl.PluralRules` هو الذي يختار:

```html
{{ child.birthDate | hbhAge }}
{{ goals.length | hbhPlural: 'progress.goalCount' }}
```

**لا تكتب مفتاحًا معدودًا بصيغة واحدة.** لو الرقم متغيّر، فالمفتاح خمسة مفاتيح.

### علامات الترقيم

حتى الفاصلة مترجَمة (`format.listSeparator`)، لأن العربية تستعمل فاصلتها الخاصة
`،` واللغة التالية ستستعمل غيرها. لا تكتب `', '` في قالب.

## 7. نظام التصميم

**كل لون توكن.** لا `hex` في مكوّن. التوكنات في `hbh-shared.css` تحت `.hbh-app`،
وهي مشتركة مع تطبيق المركز — تغييرها يمسّ التطبيقين.

الأصناف الجاهزة، استعملها ولا تكتب بديلًا:

| | |
|---|---|
| السطح | `.hbh-card` `.hbh-card-head` `.hbh-card-body` |
| الأزرار | `.hbh-btn--primary` `--ghost` `--block` |
| الشارات | `<hbh-status-badge [status]>` — لا تكتب شارة بيدك |
| الصفوف | `.row` `.row__ic` `.row__b` `.row__e` |
| الأقسام | `.sec` `.sec__head` `.sec__t` `.stack` |
| التلوين | `.hbh-t--blue` `--green` `--amber` `--purple` `--navy` `--red` |
| الحالات | `<hbh-skeleton>` `<hbh-empty-state>` `<hbh-error-note>` |

**الأيقونات من الـ sprite وحده.** `<hbh-icon name="ic-calendar" />`، والاسم من
اتحاد `IconName` — فالخطأ المطبعي خطأ بناء لا أيقونة ناقصة عند المستخدم. أيقونة
جديدة تُضاف إلى `icon-sprite.html` **وإلى الاتحاد** معًا.

**درجات `-500` تعبئة، و`-600` نصّ.** درجات الشعار لا تبلغ 4.5:1 على الأبيض.
هذا الانضباط مطبَّق على الفيروزي وحده حتى الآن — والألوان الدلالية تحته؛ راجع
مراجعة التصميم المفتوحة.

**والمرجاني لون هوية لا لون خطأ.** لا تستعمله لحالة فشل أبدًا حتى لا يختلط
بـ `--hbh-danger`.

## 8. الأمن — ما تفعله الواجهة وما لا تفعله

**القاعدة: الواجهة ترسم الرفض، ولا تصنعه.**

- **الهوية تفشل مقفولة.** لا توكن ← الحارس يرسل إلى تسجيل الدخول. لا شاشة نصف
  مرسومة أبدًا.
- **التوكن معتِم.** يُرفَق ولا يُفكَّك. كل ادّعاء بداخله شأن الخادم، وقراءته هنا
  فحصٌ يستطيع العميل تعديله.
- **`sessionStorage` لا `localStorage`.** جلسة وليّ أمر لا تعمّر بعد التبويب على
  هاتف عائلي.
- **`401` وحده ينهي الجلسة. `403` لا.** الـ 403 يعني أن الخادم عرف مَن أنت ورفض
  هذا الشيء تحديدًا — وتسجيل الخروج عليه يخفي حدّ الصلاحية خلف شاشة دخول.
- **حزم الترجمة لا تحمل توكنًا** (`assets/` مستثناة في الاعتراض): ملف ساكن، وإرسال
  توكن الجلسة معه يضعه في سجلّ بلا سبب.
- **اختيار الطفل ليس منحة.** الخادم يعيد فحص صلة وليّ الأمر في **كل** نداء؛ المعرّف
  المحفوظ يوفّر رحلة ولا يمنح شيئًا، والمعرّف المزوَّر يذهب إلى شاشة الاختيار.
- **الهاتف يُقنَّع على الجهاز** لا في الخادم — فالأرقام لا تسافر مرة ثانية.
- **`markMoment` ملاحظة سريرية بختم زمني**، لا مؤشّر داخل تسجيل. لا تضف حقلًا
  يوحي بغير ذلك.

## 9. الاختبارات

القائم اليوم أربعة ملفات `*.spec.ts` — كلها في `core`، وكلها تختبر ما يصعب رؤيته
بالعين: الجمع العربي، تنسيق التاريخ عبر المناطق الزمنية، قراءة رفض الرمز، الجلسة.

**وهذا هو المعيار: اختبر ما يفشل صامتًا.** منطق منطقة زمنية، صيغة جمع، قراءة رمز
خطأ، حارس. لا تختبر أن قالبًا يعرض نصًّا.

### مجموعة القبول W1 — التباين

```bash
bash tests/web/w1_contrast_verify.sh
```

٣١ فحصًا على `html/hbh-shared.css`: كل زوج (لون نصّ، خلفية) يُحسَب فعليًا بمعادلة
WCAG في awk بلا أي اعتماد، وثلاث **قواعد بنيوية** تمسك الخرق الذي لم يكتبه أحد
بعد — توكن تعبئة استُعمل نصًّا، أو `--hbh-muted` استُعمل خلفية، أو `hex` حرفي خارج
ملف التوكنات.

والاستثناءات في `tests/web/contrast-exemptions.tsv` **بسبب مكتوب**، لا داخل ملف
الاختبار: قاعدة استثناءاتها في اختبارها هي قاعدة تعدّلها كل دفعة بصمت. وعتبة الزوج
المستثنى هي **نسبته اليوم**، فلا يستطيع أن يسوء دون أن تفشل المجموعة، والدَّين يُطبع
بأرقامه في كل تشغيلة.

**لا يوجد اختبار e2e للبوابة بعد.** `tests/e2e/` موجود وفارغ، وهو المكان.

## 10. عقد الـ API — فجوة أُغلقت، والدرس باقٍ

> **حالة هذا القسم: مُغلَق.** كُتب في 2026-09-03 وهو يصف عيبًا قائمًا، وأُغلق في
> 09-05. بقي هنا لأن السبب الذي أنتجه لم يُغلَق — وهو يتكرّر في أي طبقة نقل
> تُكتب قبل أن يستقرّ ما تنقله.

### ما كان

`HttpPortalApi` كان يكتب `this.http.get<HomeSummary>(…)` ولا شيء غير ذلك. والـ
generic في `HttpClient` **ادّعاء وقت ترجمة، لا فحص وقت تشغيل**: لم يكن في المشروع
تحقّق ولا تحويل. وما يرجعه الـ API (`docs/02-api-contract.md`) كان يختلف عن
النماذج في خمسة مستويات:

| | النماذج في `portal.models.ts` | الـ API |
|---|---|---|
| التسمية | `fullName`, `startsAt` | `full_name_ar`, `starts_at` |
| المعرّفات | `Uuid = string` | `"child_id": 41` — **أعداد صحيحة** |
| البنية | `serviceName: string` مسطّح | `"service": { "name_ar", … }` **متداخل** |
| الغلاف | مصفوفة مجرّدة | `{ "appointments": [ … ] }` |
| المال | `amount: number` | `"total_amt": "4000.00"` — **نصّ عشري** (D-25) |

**والنتيجة لم تكن خطأً يظهر.** الحقل المفقود يصير `undefined`، والقالب يطبع
فراغًا، ولا استثناء في أي مكان. تطبيق كامل من الفراغات الصامتة — وهو تمامًا نوع
العطب الذي كُتب من أجله قسم «دروس مدفوعة الثمن»: نجاحٌ مُبلَّغ عنه ولم يحدث.

وشاشة البثّ كانت تخالف **D-24** نصًّا: `StreamTicket` يحمل `token: string`،
والمسار المنادى `/sessions/{id}/stream-ticket`.

### ما أُغلق به — وهو الاتجاه الصحيح

**العقد ثبت، والعميل هو الذي تحرّك.** لا لأن العقد أقدم، بل لأن ٦٦٥ فحصًا فوق
HTTP حقيقي مبنيّة عليه: تغيير شكل الرد إرضاءً لقالب يكسرها، والقالب أرخص من العقد
بمراحل.

أُعيدت كتابة `http-portal-api.ts` كطبقة تحويل — من ١٢٦ سطرًا إلى ٧٩٥ — بأشكال
`*Dto` بأسماء الخادم ودوال تحويل صريحة. والشاشات لم تتغيّر، وهذا هو المقصود من
وجود `PortalApi` مجرّدة أصلًا.

ومعها D-24: `StreamTicket` لم يعد يحمل توكنًا (بقي `expiresAt` و`playbackUrl`)،
والمسار صار `/sessions/{id}/stream`، و`withCredentials` مضبوط.

### الدرس الذي لا يُغلق

**الـ generic في `HttpClient` ليس فحصًا.** `http.get<T>()` يقول للمترجم «افترض
أن هذا T» ولا يسأل الشبكة عن شيء. أي طبقة نقل تُكتب على عقد لم يُقرأ سطرًا سطرًا
تنتج الشكل نفسه من العطب: بناء أخضر، وشاشة فارغة، ولا رسالة في أي مكان.

وثلاثة أشياء تبقى مطلوبة ولم تُبنَ بعد:

1. **تحقّق وقت تشغيل عند الحدّ.** التحويل موجود، لكن حقلًا مفقودًا ما زال يمرّ
   إلى `undefined` بدل أن **يرفع**. الطبقة تترجم ولا تتحقّق بعد.
2. **الـ fixtures تتكلّم لغة النماذج لا لغة الخادم** — أي أنها تختبر ما بعد
   التحويل، لا التحويل نفسه. فالطبقة التي أُنشئت لتُصلح الفجوة هي الوحيدة التي
   لا يغطّيها شيء.
3. **اختبار قبول في `tests/e2e/`** يشغّل البوابة على الـ API الحقيقي ويؤكّد أن
   شاشة واحدة على الأقل امتلأت فعلًا. الفراغ الصامت لا يمسكه إلا هذا، ولا يزال
   `tests/e2e/` فارغًا.

**وحالة `503 STREAM_UNAVAILABLE`** ما زالت الإجابة الافتراضية لأي تركيب جديد حتى
يضبط إنسانٌ نفقًا مُسمّى (D-19) — فهي أوّل ما يراه أوّل مختبِر، لا حالة حافّة.
